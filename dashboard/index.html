How the value is worked out

These protocols already have a token that trades, so the radar never ranks them. It learns from them instead: each one's market cap over its TVL is a vote on what its category's launches are worth, and the board's multiples are the medians of these votes.

Built from one sealed snapshot; the page runs with no network and every figure on it is in its data file.
